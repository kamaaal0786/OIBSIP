# **🔐 PassGen Tool**

A clean, minimalist desktop password generator built with Python.

I created this project to explore **GUI development** and **secure data handling**. Unlike basic command-line generators, this tool focuses on User Experience (UX) by providing immediate visual feedback on password strength and simplifying the copying process.

## **🚀 Key Features**

* **Smart Strength Meter:** A dynamic visual indicator that evaluates password strength in real-time based on length and character variety (Weak/Moderate/Strong).  
* **Customizable Security:** Users have full control over character sets (Uppercase, Lowercase, Numbers, Symbols) to meet specific website requirements.  
* **Clipboard Integration:** Built-in functionality to copy the generated password to the clipboard with a single click, preventing transcription errors.  
* **Minimalist UI:** A custom-styled interface built with Tkinter, designed to be clean, distraction-free, and easy to use.

## **🛠️ Tech Stack**

* **Language:** Python 3.x  
* **Interface:** Tkinter (Standard Library)  
* **Logic:** Random & String modules  
* **OS:** Cross-platform (Windows, macOS, Linux)
